# Документация пользователя

## 1. О приложении

ONVIF PTZ Controller — desktop-приложение для управления ONVIF-совместимыми камерами.

Приложение поддерживает:

- подключение нескольких камер
- просмотр видеопотока в реальном времени
- управление PTZ
- работу с пресетами
- сохранение камер локально
- Matrix mode для одновременного просмотра нескольких камер
- изменение части параметров камеры через ONVIF Device Management

## 2. Системные требования

### 2.1 Минимальные требования

- Windows 10/11, Linux или macOS
- Python 3.11+ при запуске из исходников
- доступ к ONVIF-камере по сети
- логин и пароль камеры

### 2.2 Что нужно для standalone-версии

Для standalone-сборки Python отдельно не нужен. Важно запускать приложение только из готовой release-папки вместе с директорией `_internal`.

## 3. Установка

### 3.1 Запуск из исходников

#### Windows

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

#### Linux / macOS

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python main.py
```

### 3.2 Запуск standalone-версии

Если у вас уже есть готовая release-сборка, запускайте:

- Windows: `release/windows-x64/onvif-ptz-controller/onvif-ptz-controller.exe`

Не переносите один `exe` отдельно. Нужно сохранять рядом каталог `_internal`.

## 4. Первый запуск

После запуска приложение открывает основное окно с тремя зонами:

- левая панель: добавление и список сохранённых камер
- центр: вкладки камер и Matrix mode
- правая панель: инструменты для активной камеры

Внизу показывается RTSP URL активного потока.

## 5. Добавление и сохранение камер

### 5.1 Добавить новую камеру

1. Нажмите **Add Camera**.
2. Выберите один из вариантов:
   - вручную укажите:
     - `Host`
     - `Port`
     - `User`
     - `Password`
  - или нажмите `Local Search`: если поле `Targets` пустое, приложение ищет камеры в текущей локальной подсети; если поле заполнено, поиск идёт только по указанному IP-адресу, префиксу, списку адресов или подсети в формате CIDR
  - в окне `Local Search` отметьте нужные камеры чекбоксами, при необходимости нажмите `Select All`, затем нажмите `Add Selected`
  - введите логин и пароль, которые будут применены ко всем выбранным камерам, после чего они будут добавлены в `Saved Cameras`
3. Если камера требует авторизацию, введите учётные данные в отдельном окне подтверждения.
4. Подтвердите добавление.

После этого камера:

- сохраняется локально
- появляется в списке Saved Cameras
- открывается в рабочем пространстве по клику на неё в Saved Cameras

### 5.2 Работа с Saved Cameras

Раздел **Saved Cameras** позволяет:

- открыть сохранённую камеру кликом
- изменить сохранённую запись через правый клик → `Edit`
- удалить сохранённую запись через правый клик → `Delete`

Если камера сейчас недоступна по сети, запись всё равно остаётся сохранённой.

## 6. Работа с вкладками и Matrix mode

### 6.1 Обычные вкладки камер

Каждая подключённая камера открывается в отдельной вкладке, как в браузере.

Поддерживается:

- переключение между вкладками
- закрытие вкладки
- переупорядочивание вкладок

### 6.2 Matrix mode

Matrix mode нужен для одновременного просмотра нескольких камер.

Как добавить камеру в Matrix:

1. Нажмите правой кнопкой по вкладке камеры.
2. Выберите **To Matrix Mode**.

Как работать в Matrix:

- клик по плитке делает камеру активной для правой панели
- drag-and-drop меняет порядок плиток
- двойной клик по плитке открывает одиночную вкладку камеры
- крестик у выбранной плитки удаляет её из Matrix

Вкладка Matrix всегда закрепляется первой, если в ней есть хотя бы одна камера.

## 7. Правая панель инструментов

У активной камеры доступны следующие разделы.

### 7.1 Info

Показывает:

- производителя
- модель
- версию прошивки
- состояние подключения
- активный профиль

### 7.2 PTZ Control

Раздел виден только для камер, которые реально поддерживают PTZ.

Режимы:

- `Continuous`
- `Relative`
- `Absolute`

Дополнительно доступны:

- кнопки направлений
- zoom in / zoom out
- скорость движения
- остановка PTZ

### 7.3 Video Streaming

Позволяет просматривать и менять параметры видеопотока активного профиля:

- encoding
- resolution
- quality
- frame rate
- bitrate
- GOP / interval-параметры

### 7.4 Imaging Settings

Позволяет изменять поддерживаемые камерой imaging-параметры. Интерфейс строится динамически по ONVIF-ответу камеры.

Типичные параметры:

- Brightness
- Contrast
- Sharpness
- Color Saturation
- Infrared / Ir Cut Filter
- Focus и другие vendor-specific поля

### 7.5 Profiles

Раздел для работы с ONVIF media profiles:

- просмотр списка профилей
- выбор активного профиля
- создание профиля
- редактирование профиля
- удаление профиля

### 7.6 Network Settings

Позволяет просматривать и частично изменять сетевые параметры камеры:

- DHCP / manual IPv4
- IP address
- subnet mask
- default gateway
- host name
- DNS
- NTP
- HTTP / HTTPS / RTSP порты
- Zero configuration
- ONVIF discovery mode

Важно: некоторые камеры не разрешают менять часть сетевых параметров или возвращают только часть полей.

### 7.7 Maintenance

Раздел содержит:

- версию прошивки
- `Soft reset`
- `Hard reset`
- `Reboot`
- `Upgrade`

Используйте эти действия осторожно. Они могут разорвать соединение с камерой или сбросить сетевые параметры.

### 7.8 User Management

Раздел позволяет:

- просматривать пользователей камеры
- создавать нового пользователя
- изменять роль или пароль существующего пользователя
- удалять пользователя

Набор ролей зависит от камеры, но обычно используются `Administrator`, `Operator`, `User`.

## 8. Управление PTZ

### 8.1 Мышью

Для PTZ доступны кнопки:

- вверх, вниз, влево, вправо
- диагонали
- zoom in
- zoom out
- stop

### 8.2 Клавиатурой

Поддерживаются:

- `W`, `A`, `S`, `D` — основные направления
- `Q`, `E`, `Z`, `C` — диагонали
- стрелки клавиатуры — основные направления
- `+` / `=` — zoom in
- `-` — zoom out
- `Space` — stop

### 8.3 Режимы PTZ

#### Continuous

Камера двигается, пока нажата кнопка или клавиша.

#### Relative

Камера смещается на небольшой шаг относительно текущей позиции.

#### Absolute

Камера переводится в конкретную позицию Pan / Tilt / Zoom.

## 9. Пресеты

В разделе Presets доступны:

- поиск пресета по имени
- обновление списка
- переход к выбранному пресету
- сохранение текущей позиции как нового пресета
- удаление пресета

Обычный сценарий:

1. Наведите камеру в нужную точку.
2. Нажмите `Save New`.
3. Выберите пресет в списке.
4. Нажмите `Go To`, чтобы вернуться к нему позже.

## 10. Горячие клавиши интерфейса

Для навигации по вкладкам доступны shortcuts:

- `Ctrl+1 ... Ctrl+9` — переход к одиночным вкладкам камер
- `Ctrl+\`` — переход к вкладке Matrix
- `Ctrl+Tab` — следующая вкладка
- `Ctrl+Shift+Tab` — предыдущая вкладка
- `Ctrl+W` — закрыть текущую вкладку

## 11. Что делать, если что-то не работает

### 11.1 Камера не подключается

Проверьте:

- правильность IP и порта
- логин и пароль
- доступность камеры по сети
- открыт ли ONVIF service на камере

### 11.2 Видео не появляется

Возможные причины:

- камера не выдаёт RTSP URI для активного профиля
- выбран неподдерживаемый профиль
- RTSP заблокирован сетью или firewall
- камера требует другой транспорт или поток закрыт политиками безопасности

Приложение сейчас пробует RTSP через UDP, а если это не удаётся, автоматически уходит в TCP fallback.

### 11.3 Есть картинка, но нет PTZ

Это нормально для камер без PTZ. В таком случае раздел PTZ Control скрывается.

### 11.4 Часть полей в Network Settings / Imaging Settings недоступна

Это означает одно из двух:

- камера не поддерживает этот параметр по ONVIF
- вендор отдаёт поле только для чтения или не отдаёт его совсем

### 11.5 Standalone `.exe` не запускается

Проверьте, что вы запускаете файл из release-папки вместе с каталогом `_internal`.

Правильно:

```text
release/windows-x64/onvif-ptz-controller/onvif-ptz-controller.exe
release/windows-x64/onvif-ptz-controller/_internal/
```

Неправильно:

- копировать только `exe`
- запускать промежуточный файл из каталога `build`

### 11.6 Список сохранённых камер пропал

Сохранённые камеры лежат в `saved_cameras.json` внутри системной папки конфигурации приложения.

Если системный путь недоступен, приложение использует резервную директорию `.onvif-ptz-controller` в текущей рабочей папке.

## 12. Практические рекомендации

- Для минимальной задержки используйте стабильную локальную сеть.
- Если камера поддерживает PTZ, сначала убедитесь, что нужный профиль и поток действительно активны.
- Перед изменением Network Settings или Maintenance-операциями желательно иметь физический доступ к камере или хотя бы резервный маршрут подключения.
