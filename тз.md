## 1. Продукт

### 1.1 Описание

Desktop-приложение для универсального управления PTZ-камерами через протокол ONVIF.

### 1.2 Цель

Создание удобного, кроссплатформенного интерфейса для дистанционного управления PTZ-камерами, совместимого с ONVIF-совместимыми устройствами

### 1.3 Основные функции

- Управление Поворотом/Наклоном/Масштабированием
- Создание и вызов пресетов
- Live-видеопоток
- Кроссплатформенность: Windows/macOS/Linux

### 1.4 Интерфейс

- Стрелочки для управления направлением — позволяют перемещать камеру вверх, вниз, влево и вправо  
  Зум — кнопки увеличения и уменьшения изображения для детального просмотра или общего плана
- Панель быстрого доступа к пресетам
- Окно предпросмотра видео
- Статус-бар: подключение, координаты, zoom
- Горячие клавиши

### 1.5 Варианты применения

**Вариант 1: Съёмка мероприятий** Оператор управляет камерой в актовом зале: переключается между пресетами (сцена/трибуна/зал), следит за выступающим, масштабирует для крупных планов.

**Вариант 2: Безопасность**
Охранник управляет камерами: патрулирует по пресетам, приближает подозрительные объекты, переключается между камерами.

**Вариант 3: Онлайн-лекции** Преподаватель управляет камерой в аудитории: следит за лектором, переключается на доску, обеспечивает качественный видеоряд.

## 2. Польза

### 2.1 Проблема

Отсутствие универсального, удобного и доступного инструмента для управления PTZ-камерами разных производителей.

**Сложности для пользователей:**

- Каждый производитель имеет своё ПО
- Высокая стоимость профессиональных решений
- Открытые аналоги устарели или ограничены

### 2.2 Наше решение

- **Унификация**: одна программа для всех ONVIF-камер
- **Доступность**: бесплатное open-source
- **Простота**: User-friendly интерфейс
- **Кроссплатформенность**: Win/Mac/Linux

## 4. Технологии

### 4.1 Архитектура

```
┌─────────────────┐
│   Frontend      │  PyQt6
│   (UI/UX)       │
└────────┬────────┘
         │
┌────────▼────────┐
│  ONVIF Client   │  python-onvif-zeep
│   (Protocol)    │
└────────┬────────┘
         │
┌────────▼────────┐
│  PTZ Cameras    │  Network
└─────────────────┘
```

### 4.2 Стек технологий

**Frontend**

- **PyQt6** 
  - Нативный внешний вид на всех платформах
  - Высокая производительность
  - Встроенная работа с мультимедиа
  - Простая упаковка (.exe/.dmg/.AppImage)
- **Python 3.11+** 
  - Единый язык для UI и ONVIF-логики
  - Типобезопасность с type hints

**ONVIF и видео**

- **python-onvif-zeep** — ONVIF клиент 
  - Поддержка Profile S/T
  - Активная разработка
- **FFmpeg** — транскодинг RTSP-потоков

**Хранение и конфигурация**

- **SQLite** — локальная БД для пресетов и настроек
- **python-dotenv** — управление конфигурацией

### 4.3 Переиспользование существующих решений

- Используем готовые ONVIF-библиотеки
- **PyQt6**: вместо нативной разработки под каждую ОС
