# ONVIF PTZ Controller — PoC

Кроссплатформенное desktop-приложение для управления PTZ-камерами через протокол ONVIF.

## Архитектура

| Файл | Назначение |
|------|-----------|
| `main.py` | Точка входа |
| `main_window.py` | Главное окно, UI-компоненты, обработка событий |
| `onvif_client.py` | ONVIF-клиент: подключение, PTZ, пресеты |
| `video_player.py` | Захват и отображение RTSP-видеопотока |

## Требования

- Python 3.11+
- Сетевой доступ к ONVIF-камере (например, через VPN)

## Установка и запуск

```bash
# 1. Клонировать репозиторий
git clone https://github.com/gorg1t/ODM.git
cd ODM

# 2. Создать виртуальное окружение
python -m venv venv

# 3. Активировать venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

# 4. Установить зависимости
pip install -r requirements.txt

# 5. Запустить приложение
python main.py
```

## Подключение к камере

1. Запустите приложение (`python main.py`).
2. В панели **Camera Connection** введите параметры:
   - **Host** — IP-адрес камеры (например, `172.18.212.18`)
   - **Port** — ONVIF-порт (по умолчанию `80`)
   - **User / Password** — учётные данные камеры
   - **RTSP URL** — адрес видеопотока
3. Нажмите **Connect**.
4. Дождитесь появления видеопотока и загрузки пресетов.

## Управление PTZ

### Кнопки

| Кнопка | Действие |
|--------|----------|
| ▲ ▼ ◀ ▶ | Поворот/наклон |
| ◤ ◥ ◣ ◢ | Диагональное движение |
| 🔍+ / 🔍− | Зум |
| ⏹ | Остановка движения |

### Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `W` | Вверх |
| `S` | Вниз |
| `A` | Влево |
| `D` | Вправо |
| `Q` | Вверх-влево |
| `E` | Вверх-вправо |
| `Z` | Вниз-влево |
| `C` | Вниз-вправо |
| `+` | Приблизить |
| `-` | Отдалить |
| `Space` | Стоп |

Ползунок **Speed** регулирует скорость перемещения.

## Пресеты

- **Refresh** — загрузить список пресетов с камеры
- **Go To** (или двойной клик) — перейти к выбранному пресету
- **Save New** — сохранить текущую позицию как пресет
- **Delete** — удалить выбранный пресет

## Стек технологий

- **PyQt6** — кроссплатформенный UI
- **onvif-zeep-async** — ONVIF-протокол (Profile S)
- **OpenCV** — RTSP-видеопоток через FFmpeg-бэкенд
- **Python 3.11+**
