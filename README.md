# ONVIF PTZ Controller — Прототип

Кроссплатформенное desktop-приложение для управления PTZ-камерами через протокол ONVIF с отображением видеопотока в реальном времени и воспроизведением звука. Приложение поддерживает несколько камер одновременно, переключение между ними через вкладки и выбор ONVIF-медиапрофиля (потока) для активной камеры.

## Архитектура

```
┌───────────────────────────┐
│    PyQt6 UI               │  Интерфейс: видео, аудио, кнопки PTZ, пресеты
│    (main_window.py)       │
└──────────┬────────────────┘
           │
     ┌─────┴─────┐
     │           │
┌────▼─────┐ ┌──▼──────────────┐
│  ONVIF   │ │  Video Player   │  PyAV (FFmpeg) — захват RTSP-потока
│  Client  │ │  (video_player  │  с минимальной задержкой
│  (onvif_ │ │   .py)          │
│  client  │ └─────────────────┘
│  .py)    │
└──────────┘
```

| Файл | Назначение |
|------|-----------|
| `main.py` | Точка входа, настройка логирования |
| `main_window.py` | Главное окно, все UI-виджеты, обработка событий, аудио |
| `onvif_client.py` | ONVIF-клиент: подключение, PTZ (continuous/relative/absolute), пресеты |
| `video_player.py` | Захват RTSP-видеопотока через PyAV с frame-skip стратегией |

## Требования

- Python 3.11+
- Сетевой доступ к ONVIF-камере (например, через VPN)
- FFmpeg-библиотеки (устанавливаются автоматически вместе с пакетом `av`)

## Установка и запуск

```bash
# 1. Клонировать репозиторий
git clone <repo-url>
cd onvif-ptz-controller

# 2. Создать виртуальное окружение
python -m venv venv

# 3. Активировать venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

# 4. Установить зависимости
pip install -r requirements.txt

# 5. Запустить приложение
python main.py
```

## Standalone build

Для сборки standalone-версии используется PyInstaller в режиме `onedir`. Это самый надёжный вариант для текущего стека `PyQt6 + PyAV + ONVIF WSDL`.

```bash
# 1. Установить build-зависимости
pip install -r requirements-build.txt

# 2. Собрать standalone bundle
python build_standalone.py
```

Готовое приложение появится в директории `release/<platform>/onvif-ptz-controller/`.

Пример для Windows:

```text
release/windows-x64/onvif-ptz-controller/
```

В этой же папке `release/` будет создан zip-архив для передачи или публикации.

Внутри bundle уже должны быть включены:
- Python runtime
- PyQt6 runtime и multimedia-модули
- PyAV native libraries
- `onvif/wsdl`, нужный для ONVIF-клиента

Важно: запускать нужно только файл `onvif-ptz-controller.exe` из готовой release-папки вместе с соседней директорией `_internal`. Нельзя копировать или запускать промежуточный exe из каталога `build`, и нельзя переносить один exe без `_internal`.

### Платформы

- Windows: запускать сборку на Windows
- Linux: запускать сборку на Linux
- macOS: запускать сборку на macOS

PyInstaller не делает полноценный кросс-компил бинарников между Windows, Linux и macOS, поэтому для каждой целевой ОС нужен native build на этой ОС.

## Подключение к камере

1. Запустите приложение (`python main.py`).
2. В панели **Camera Connection** введите параметры:
   - **Host** — IP-адрес камеры (например, `172.18.212.18`)
   - **Port** — ONVIF-порт (по умолчанию `80`)
   - **User / Password** — учётные данные камеры
3. Нажмите **Add Camera**. Для каждой подключённой камеры создаётся отдельная вкладка.
4. При выборе вкладки справа отображаются подробности выбранной камеры и список доступных потоков ONVIF.
5. Выберите нужный поток в поле **Stream**. RTSP-адрес активного потока получается автоматически через ONVIF (`GetStreamUri`).
6. Видео и аудио начнут воспроизводиться автоматически для выбранной вкладки.

## Работа с несколькими камерами

- Каждая подключённая камера открывается в отдельной вкладке, аналогично вкладкам в браузере.
- Закрытие вкладки или кнопка **Remove Camera** отключает только выбранную камеру.
- PTZ-управление, пресеты, статус и аудио всегда относятся к текущей активной вкладке.
- Если камера предоставляет несколько медиа-профилей, между ними можно переключаться в боковой панели без переподключения камеры.

## Управление PTZ

### Режимы движения

Переключаются через выпадающий список **Mode** в панели PTZ Control:

| Режим | Описание |
|-------|----------|
| **Continuous** | Непрерывное движение, пока кнопка нажата. Останавливается при отпускании. |
| **Relative** | Смещение на заданный шаг (настраивается в поле **Step**) относительно текущей позиции. |
| **Absolute** | Перемещение в абсолютную позицию (Pan/Tilt/Zoom). Задаётся в полях ввода + кнопка **Go To Position**. |

### Кнопки направлений

| Кнопка | Действие |
|--------|----------|
| ▲ ▼ ◀ ▶ | Поворот/наклон |
| ◤ ◥ ◣ ◢ | Диагональное движение |
| 🔍+ / 🔍− | Зум |
| ⏹ | Остановка движения |

### Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `W` | Вверх |
| `S` | Вниз |
| `A` | Влево |
| `D` | Вправо |
| `Q` | Вверх-влево |
| `E` | Вверх-вправо |
| `Z` | Вниз-влево |
| `C` | Вниз-вправо |
| `+` | Приблизить |
| `-` | Отдалить |
| `Space` | Стоп |

Ползунок **Speed** регулирует скорость перемещения (для режимов Continuous и Relative).

## Пресеты

- **Search** — поле поиска с фильтрацией пресетов в реальном времени
- **Refresh** — загрузить список пресетов с камеры
- **Go To** (или двойной клик) — перейти к выбранному пресету
- **Save New** — сохранить текущую позицию как новый пресет
- **Delete** — удалить выбранный пресет

## Аудио

- Звук с камеры воспроизводится автоматически при подключении (через `QMediaPlayer` / RTSP)
- В статус-баре доступны кнопка **Mute/Unmute** и ползунок **Volume**

## Стек технологий

| Компонент | Технология | Назначение |
|-----------|-----------|------------|
| UI | **PyQt6 ≥ 6.5** | Кроссплатформенный интерфейс, тёмная тема |
| ONVIF | **onvif-zeep-async ≥ 1.2** | Протокол ONVIF Profile S — PTZ, пресеты, получение RTSP URI |
| Видео | **PyAV (av ≥ 12.0)** | Прямые биндинги FFmpeg — захват RTSP с минимальной задержкой |
| Аудио | **PyQt6.QtMultimedia** | Воспроизведение аудиодорожки RTSP-потока |
| Язык | **Python 3.11+** | Единый язык для UI и сетевой логики |
