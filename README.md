# ONVIF PTZ Controller - Website

Современный одностраничный сайт для ONVIF PTZ Controller приложения с интеграцией GitHub Releases API.

## Быстрый старт

### 1. Обновите конфигурацию

Откройте `script.js` и замените:

```javascript
const GITHUB_REPO = 'yourusername/onvif-ptz-controller';
```

на ваш реальный GitHub репозиторий, например:

```javascript
const GITHUB_REPO = 'ivanov/onvif-ptz-controller';
```

### 2. Обновите ссылки в HTML

В `index.html` найдите и замените все упоминания `yourusername/onvif-ptz-controller` на ваш репозиторий.

### 3. Создайте релиз

Сайт автоматически загружает последний релиз через GitHub API:

1. Перейдите в основную ветку проекта
2. Соберите standalone версию: `python build_standalone.py`
3. На GitHub: Releases → Create a new release
4. Загрузите собранные файлы:
   - `onvif-ptz-controller-windows-x64.zip`
   - `onvif-ptz-controller-linux-x64.tar.gz`
   - `onvif-ptz-controller-macos.dmg`
5. Опубликуйте релиз

**Важно:** Сайт автоматически определяет платформу по имени файла (должно содержать 'windows', 'linux', 'macos') или расширению (.zip, .tar.gz, .dmg).

### 4. Активируйте GitHub Pages

1. Settings → Pages
2. Source: Deploy from a branch
3. Branch: `gh-pages` → `/` (root)
4. Save

Сайт будет доступен: `https://yourusername.github.io/repository-name`

## Запуск локально

Просто откройте `index.html` в браузере:

```bash
# Windows
start index.html

# Linux
xdg-open index.html

# macOS
open index.html
```

Или используйте локальный сервер для разработки:

```bash
# Python 3
python -m http.server 8000

# Node.js (если установлен)
npx http-server

# VS Code Live Server extension
# Right-click на index.html → "Open with Live Server"
```

Затем откройте `http://localhost:8000` в браузере.

## Настройка

### Изменить цветовую схему

Отредактируйте CSS-переменные в `style.css`:

```css
:root {
    --primary: #3b82f6;      /* Основной цвет */
    --primary-dark: #2563eb; /* Темный вариант */
    --secondary: #8b5cf6;    /* Вторичный цвет */
    --dark: #0f172a;         /* Темный фон */
    /* ... */
}
```

### Добавить реальные ссылки для скачивания

В `index.html` замените `href="#"` на реальные URL:

```html
<a href="https://example.com/releases/onvif-ptz-controller-windows.zip" class="btn btn-download">
    Скачать .zip
</a>
```

### Добавить аналитику

Вставьте код Google Analytics или Yandex.Metrika перед закрывающим тегом `</body>` в `index.html`.

### Добавить скриншоты приложения

Замените демо-виджеты на реальные скриншоты:

```html
<div class="demo-video">
    <img src="images/screenshot.png" alt="ONVIF PTZ Controller">
</div>
```
