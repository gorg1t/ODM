# Отчёт: ONVIF PTZ Controller — Прототип

## 1. Описание продукта

**ONVIF PTZ Controller** — desktop-приложение для дистанционного управления PTZ-камерами (Pan/Tilt/Zoom) через стандартный протокол ONVIF. Приложение обеспечивает отображение видеопотока в реальном времени, воспроизведение звука с камеры и полноценное управление поворотом, наклоном и масштабированием.

Текущая стадия: **Прототип** (согласно плану разработки — этап между PoC и MVP).

## 2. Архитектура

### 2.1 Общая схема

│         │            │           │            │      │
└─────────┼────────────┼───────────┼────────────┼──────┘

  │  PyAV     │   │       ONVIF Client             │

  │           │   │  get_presets / goto_preset     │

        │  RTSP / H.264          │  ONVIF / SOAP

### 2.2 Компоненты

| Модуль | Файл | Ответственность |
|--------|------|-----------------|
| **Точка входа** | `main.py` | Настройка логирования, создание `QApplication` и `MainWindow` |
| **Главное окно** | `main_window.py` | Все UI-виджеты, обработка событий пользователя, управление аудио через `QMediaPlayer`, координация между компонентами |
| **ONVIF-клиент** | `onvif_client.py` | Асинхронное подключение к камере через `onvif-zeep-async`, вызов ONVIF-сервисов (DeviceMgmt, Media, PTZ) |
| **Видеоплеер** | `video_player.py` | Захват RTSP-потока в отдельном `QThread` через PyAV (FFmpeg), конвертация кадров в `QImage` |

### 2.3 Потоки данных

1. **Подключение**: Пользователь вводит IP/Port/логин/пароль → `ONVIFPTZClient.connect()` устанавливает SOAP-соединение → получает информацию об устройстве и медиа-профиль.
2. **Видеопоток**: RTSP URI получается через `get_stream_uri()` → `VideoStreamThread` открывает поток через PyAV с low-latency опциями FFmpeg → декодирует H.264 кадры → эмитит `QImage` через сигнал `frame_ready` → `VideoWidget.update_frame()` отображает на экране.
3. **Аудиопоток**: Тот же RTSP URI передаётся в `QMediaPlayer` → воспроизведение аудиодорожки через `QAudioOutput`.
4. **PTZ команды**: Нажатие кнопки/клавиши → `MainWindow._on_ptz_move()` определяет режим → вызывает соответствующий метод ONVIF-клиента (`continuous_move` / `relative_move` / `absolute_move`).
5. **Статус**: `QTimer` каждую секунду вызывает `get_status()` → обновляет координаты Pan/Tilt/Zoom в статус-баре.

### 2.4 Многопоточность

- **Основной поток (GUI)**: PyQt6 event loop, обработка пользовательского ввода, отображение кадров.
- **Видеопоток (`VideoStreamThread`)**: Отдельный `QThread` — захват и декодирование RTSP. Связь с GUI через сигнал `frame_ready`.
- **ONVIF-вызовы**: Выполняются синхронно через `asyncio.loop.run_until_complete()` в GUI-потоке (блокируют GUI на время SOAP-запроса, что допустимо для прототипа, т.к. запросы быстрые).

## 3. UX-решения

### 3.1 Тёмная тема

Приложение использует тёмную цветовую схему (`#0f0f23` — основной фон, `#1a1a2e` — поля ввода, `#3498db` — акценты). Выбор обусловлен:
- Операторы видеонаблюдения часто работают в затемнённых помещениях
- Снижение утомляемости глаз при длительной работе
- Современный внешний вид

### 3.2 Компоновка интерфейса

```
┌────────────────────────────────────────────────────────┐
│  Camera Connection: [Host] [Port] [User] [Pass]        │
│  [Connect]  [Disconnect]                               │
├──────────────────────────────┬─────────────────────────┤
│                              │  PTZ Control            │
│                              │  Mode: [Continuous ▾]   │
│      Видеопоток              │  [◤] [▲] [◥]           │
│      (масштабируется         │  [◀] [⏹] [▶]          │
│       по размеру окна)       │  [◣] [▼] [◢]           │
│                              │  [🔍−  Zoom Out]       │
│                              │  [🔍+  Zoom In]        │
│                              │  Speed: [────●────]     │
│                              ├─────────────────────────┤
│                              │  Presets                │

│                              │  │ Preset 2          │  │

```

- **Splitter** разделяет видео (3/4 ширины) и панель управления (1/4). Пользователь может изменять пропорции перетаскиванием.
- **Правая панель** обёрнута в `QScrollArea` — при малых размерах окна элементы управления остаются доступными через прокрутку.
- **Минимальная ширина правой панели** — 320px, чтобы кнопки и поля ввода не сжимались.

### 3.3 Режимы PTZ

Выпадающий список `QComboBox` позволяет переключаться между тремя режимами:

| Режим | Когда использовать | Визуальные элементы |
|-------|-------------------|---------------------|
| **Continuous** | Слежение за объектом в реальном времени | Только стандартные кнопки + Speed ползунок |
| **Relative** | Точная коррекция позиции шагами | Появляется поле «Step» (0.01–1.0) |
| **Absolute** | Перемещение в известную координату | Появляются поля Pan/Tilt/Zoom + кнопка «Go To Position» |

Дополнительные панели (Absolute Position, Relative Step Size) показываются/скрываются динамически при смене режима.

### 3.4 Автоматическое получение RTSP URL

В отличие от PoC, пользователю не нужно вручную указывать RTSP-адрес. Адрес видеопотока получается автоматически через ONVIF-метод `GetStreamUri`, а учётные данные (логин/пароль) подставляются в URL. Это упрощает подключение и исключает ошибки ввода.

### 3.5 Поиск пресетов

Поле поиска с `clearButton` — фильтрует список пресетов в реальном времени по имени (case-insensitive). Полезно при большом количестве пресетов на камере.

### 3.6 Аудио

- Звук воспроизводится автоматически при подключении
- Управление в статус-баре: кнопка mute/unmute (`🔊`/`🔇`) и ползунок громкости
- Транспорт — TCP (параметр `?rtsp_transport=tcp` добавляется к RTSP URL), что исключает потерю аудиопакетов

### 3.7 Горячие клавиши

Управление PTZ доступно с клавиатуры (WASD + QE + ZC для направлений, +/- для зума, Space для стоп). Реализовано через `keyPressEvent`/`keyReleaseEvent` с фильтрацией `autoRepeat`. В режиме Continuous отпускание клавиши автоматически останавливает движение.

### 3.8 Статус-бар

Реализованы три индикатора:
- **Подключение**: «Disconnected» / «Connected: HIKVISION DS-2DE2204IW-DE3/W»
- **Координаты**: обновляются каждую секунду через `GetStatus` (Pan, Tilt, Zoom + индикатор `[Moving]`)
- **Видеопоток**: «Stream: Off» / «Stream: Active ✓» / «Stream: Error — ...»

## 4. Техническое решение по снижению задержки видео

### 4.1 Проблема

При захвате RTSP-потока (H.264, 1920×1080, 25fps) типичная задержка составляет 1–3 секунды из-за буферизации на уровне RTSP-клиента, демультиплексора и декодера.

### 4.2 Решение: PyAV + frame-skip стратегия

Вместо OpenCV используется **PyAV** — прямые Python-биндинги к FFmpeg, что даёт полный контроль над параметрами захвата:

```python
options = {
    'rtsp_transport': 'udp',           # минимальная задержка транспорта
    'rtsp_flags': 'prefer_tcp',        # fallback на TCP при проблемах
    'fflags': 'nobuffer+discardcorrupt',
    'flags': 'low_delay',
    'max_delay': '0',
    'reorder_queue_size': '0',
    'analyzeduration': '0',
    'probesize': '32768',
}
```

**Frame-skip стратегия**: Все кадры декодируются (необходимо для корректности H.264), но на экран выводится не более 30 fps. Если декодирование обгоняет отображение (например, при начальном заполнении буфера), лишние кадры пропускаются:

```python
EMIT_INTERVAL = 1.0 / 30
for frame in packet.decode():
    now = time.monotonic()
    if now - last_emit_time < EMIT_INTERVAL:
        continue  # декодируем, но не отображаем
    # ... конвертация и emit
    last_emit_time = now
```

### 4.3 Автоматический реконнект

При обрыве соединения видео-поток автоматически восстанавливается (до 5 попыток с задержкой 3 секунды).

## 5. Инструкции по запуску

### 5.1 Системные требования

- **ОС**: Windows 10/11, macOS 12+, Linux (Ubuntu 22.04+)
- **Python**: 3.11 или новее
- **Сеть**: доступ к ONVIF-камере (прямой или через VPN)

### 5.2 Установка

```bash
git clone <repo-url>
cd onvif-ptz-controller

python -m venv venv

# Windows:
venv\Scripts\activate
# Linux / macOS:
source venv/bin/activate

pip install -r requirements.txt
```

### 5.3 Запуск

```bash
python main.py
```

### 5.4 Подключение к камере

1. Введите IP-адрес, порт, логин и пароль камеры.
2. Нажмите **Connect**.
3. При успешном подключении:
   - В статус-баре отобразится модель камеры
   - Автоматически запустятся видео- и аудиопотоки
   - Загрузится список пресетов
