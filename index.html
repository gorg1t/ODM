О продукте

ONVIF PTZ Controller — это профессиональное desktop-приложение для управления IP-камерами стандарта ONVIF. Приложение разработано для систем видеонаблюдения, где критична скорость реакции и точность управления.

Минимальная задержка

Прямой захват RTSP-потока через FFmpeg без промежуточных буферов. Задержка менее 300ms.

Множественный просмотр

Matrix mode для одновременного мониторинга до 16 камер на одном экране.

Полный контроль

PTZ-управление, пресеты, настройка изображения, сетевых параметров и пользователей камеры.

Автообнаружение

WS-Discovery для автоматического поиска ONVIF-камер в локальной сети.

Ключевые возможности

PTZ-управление

  • Continuous mode — непрерывное движение при удержании кнопки
  • Relative mode — смещение на заданный шаг
  • Absolute mode — перемещение в точные координаты
  • Регулируемая скорость движения и зум
  • Горячие клавиши (WASD, стрелки, +/-)

Управление камерой

  • Пресеты — сохранение и быстрый переход к позициям

Кейсы применения

Конференц-центр «Технопарк»

Видеопродакшн

Задача

Оператору нужно управлять 8 PTZ-камерами во время live-трансляций конференций. VMS не давала достаточно точного контроля, а задержка видео 2-3 секунды приводила к ошибкам кадрирования.

Решение

ONVIF PTZ Controller с Matrix mode на втором мониторе. Оператор видит все 8 камер одновременно, переключается горячими клавишами Ctrl+1...8, использует сохраненные пресеты для типовых ракурсов.

Результат

  • Задержка видео снижена с 2-3 сек до 250ms
  • Время настройки камеры перед конференцией сократилось с 30 до 5 минут через сохраненные пресеты
  • Ошибки кадрирования устранены благодаря точному Relative mode

Логистический терминал «ЕвроТранс»

Промышленность

Задача

На территории склада площадью 12 га установлено 24 PTZ-камеры разных производителей. Существующее ПО не поддерживало часть камер, для других требовались отдельные клиенты.

Решение

Миграция на ONVIF PTZ Controller. Автообнаружение нашло все 24 камеры за 8 секунд, сохранённые камеры организованы по зонам. Диспетчер переключается между зонами через вкладки.

Результат

  • Все камеры работают через единый интерфейс независимо от производителя
  • Среднее время реакции на инцидент сокращено с 45 до 12 секунд
  • Отказались от 3 разных клиентов в пользу одного приложения

Интегратор «СистемыБезопасности»

Системная интеграция

Задача

Компания устанавливает системы видеонаблюдения на объектах заказчиков. Инженерам требовалось тестировать и настраивать камеры на месте, но веб-интерфейсы камер часто глючили или были недоступны.

Решение

ONVIF PTZ Controller на служебных ноутбуках инженеров. Приложение не требует установки (standalone build), работает через ONVIF без доступа к веб-интерфейсу. Network Settings позволяют настроить IP прямо из приложения.

Результат

  • Время настройки одной камеры сократилось с 15 до 4 минут
  • Количество повторных выездов по причине неправильной конфигурации снизилось на 68%
  • Инженеры могут настраивать камеры через VPN без физического присутствия

Университет МИЭМ НИУ ВШЭ

Образование

Задача

В 12 лекционных залах установлены PTZ-камеры для записи лекций. Преподаватели должны самостоятельно управлять камерой через планшет, но заводское приложение было сложным и медленным.

Решение

Развертывание ONVIF PTZ Controller на планшетах Surface. Для каждого зала созданы 3 пресета: «доска», «преподаватель», «аудитория». Преподавателю достаточно одного клика для переключения ракурса.

Результат

  • 95% преподавателей освоили управление камерой за первую лекцию (было 30%)
  • Количество технических вызовов снизилось с 8-10 в неделю до 1-2
  • Качество записей улучшилось за счет динамической смены ракурсов
