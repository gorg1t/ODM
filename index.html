О продукте

ONVIF PTZ Controller — это профессиональное desktop-приложение для управления IP-камерами стандарта ONVIF. Приложение разработано для систем видеонаблюдения, где критична скорость реакции и точность управления.

Минимальная задержка

Прямой захват RTSP-потока через FFmpeg без промежуточных буферов. Задержка менее 300ms.

Множественный просмотр

Matrix mode для одновременного мониторинга до 16 камер на одном экране.

Полный контроль

PTZ-управление, пресеты, настройка изображения, сетевых параметров и пользователей камеры.

Автообнаружение

WS-Discovery для автоматического поиска ONVIF-камер в локальной сети.

PTZ-управление

  • Continuous mode — непрерывное движение при удержании кнопки
  • Relative mode — смещение на заданный шаг
  • Absolute mode — перемещение в точные координаты
  • Регулируемая скорость движения и зум
  • Горячие клавиши (WASD, стрелки, +/-)

Управление камерой

  • Пресеты — сохранение и быстрый переход к позициям
  • Video Streaming — настройка разрешения, bitrate, framerate
  • Imaging Settings — яркость, контраст, резкость, ИК-фильтр
  • Network Settings — IP, DNS, NTP, порты
  • User Management — управление пользователями и правами

Работа с несколькими камерами

  • Browser-style вкладки — каждая камера в отдельной вкладке
  • Matrix mode — одновременный просмотр до 16 камер
  • Drag-and-drop — переупорядочивание вкладок и плиток
  • Saved Cameras — локальная библиотека с избранными камерами
  • Быстрое переключение между камерами через Ctrl+1...9

Кейсы применения

Конференц-центр «Технопарк»

Видеопродакшн

Задача

Оператору нужно управлять 8 PTZ-камерами во время live-трансляций конференций с возможностью слышать происходящее и быстро реагировать на изменения.

Преимущества над ODM

Matrix Mode позволяет видеть все 8 камер одновременно на втором мониторе. Поддержка аудио дает возможность слышать выступающего и координировать работу. Удобный интерфейс с горячими клавишами Ctrl+1...8 для мгновенного переключения.

Результат

  • Одновременный просмотр всех камер через Matrix Mode избавил от необходимости переключаться вслепую
  • Аудио с камер помогает оператору понимать контекст происходящего без дополнительных мониторов
  • Минимальная задержка видео (<300ms) обеспечивает точное кадрирование в реальном времени

Логистический терминал «ЕвроТранс»

Промышленность

Задача

На территории склада площадью 12 га установлено 24 PTZ-камеры разных производителей. Нужен единый инструмент для мониторинга всех зон независимо от операционной системы.

Преимущества над ODM

Мультиплатформенность — диспетчеры работают на Windows, Linux и macOS. Matrix Mode позволяет организовать камеры по зонам и видеть все 24 одновременно. Удобный дизайн с вкладками упрощает переключение между зонами.

Результат

  • Единое приложение работает на всех компьютерах диспетчерской независимо от ОС
  • Matrix Mode с организацией по зонам позволяет контролировать весь периметр на одном экране
  • Интуитивный интерфейс с вкладками ускорил обучение новых диспетчеров

Университет МИЭМ НИУ ВШЭ

Образование

Задача

В 12 лекционных залах установлены PTZ-камеры для записи лекций. Преподаватели должны самостоятельно управлять камерой, но многим сложно разобраться в технике.

Преимущества над ODM

Удобный дизайн с минималистичным интерфейсом — преподаватели осваивают за минуты. Поддержка аудио позволяет контролировать качество звука записи. Пресеты для типовых ракурсов: «доска», «преподаватель», «аудитория».

Результат

  • Интуитивный интерфейс — преподаватели управляют камерой без технической поддержки
  • Аудиомониторинг помогает убедиться в качестве записи до начала лекции
  • Пресеты упрощают работу — один клик для смены ракурса
